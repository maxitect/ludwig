The user enabled branch-per-preview in the Vercel storage settings. The redeploy created `preview/ticket/t009-spike-vercel-neon` (`br-round-meadow-zacymqjt`, `creation_source: vercel`).
3. **Sign-in action 500 on previews.** Runtime logs: `TypeError: Failed to parse URL from undefined/api/auth/sign-in/email`. The T008 action built its Request from `env.BETTER_AUTH_URL`, which is optional on previews. Fix: `auth.ts` exports `authBaseURL` (the same `BETTER_AUTH_URL ?? https://${VERCEL_URL}` resolution) and the action uses it.
4. **Preview protection.** Unchanged; reached with `vercel curl --yes --deployment <url>` and a Vercel MCP share link for the browser.
