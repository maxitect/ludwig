## Deviations and follow-ups

- **Toaster is not mounted in the root layout.** It is left for T015 so this ticket does not touch `layout.tsx` (T013 runs in parallel). The test page mounted it itself.
- The shadcn CLI re-added the wrong `cn` npm package and `next-themes`; both removed. Imports point to `@/utils/cn`. `lucide-react` was missing from dependencies (the `components.json` icon library) so it was added. `sonner` added.
- `next-themes` is not used. Sonner is `unstyled` with token classes, so it follows the `data-theme` variables (sonner's own unlayered CSS would otherwise beat Tailwind utilities).
- No `tw-animate-css` in the project, so shadcn's `animate-in`/`slide-*`/`zoom-*` classes were dead; removed. The sheet therefore has no slide animation yet (T015 can add one with reduced-motion handling).
- Rotation uses `[transform:rotate(-0.5deg)]` with `inset-0 m-auto h-fit` centring, because Tailwind v4 `rotate-*` sets the separate `rotate` property and would leave computed `transform` as `none`. Toasts get the same static rotation.
- Dialog/AlertDialog title is `Credit`-style caps by classes only, as `src/components/brand/Credit` does not exist yet.
- Sheet grain comes from the global `body::before` overlay (as in T011), not a per-element texture. Sheet has an ink border on its leading edge only, no shadow.
- Menu item focus is an ink-fill inversion (blue is reserved for focus rings and book covers). Destructive items are bold with a blood fill on focus, as ludwig-red/blood text fails contrast on Ink.
- The loading toast icon is a static hourglass (no spinners per design rules).
- The Next dev indicator badge overlaps the bottom-left toast in the 390px screenshots (dev only).
- `pnpm typecheck` still needs `.next` typegen first (pre-existing, see T011).
- Early in setup my `sed` for `.env.local` failed and one `pnpm db:migrate` ran against the shared `ludwig` database. It reported already-applied migrations, so no change. Fixed and re-run against `ludwig_t012`.
