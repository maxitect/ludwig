## Deviations and follow-ups

- The route sets `metadata.icons.icon = "data:,"`. The repo has no favicon, so `/favicon.ico` 404s and would break AC7. A real favicon should be added globally later, then this line can go.
- Screenshots taken with Playwright MCP inject `caret-color: transparent` into inputs. If the page is reloaded afterwards, React logs a hydration-mismatch error (and the dev log shows it). It is a tool artifact: a fresh browser session without screenshots has a clean console. Overlays were verified in such a session.
- The coverage test scans all `.tsx` files in the kitchen-sink folder (not only `page.tsx`), because client demos (form, overlays, toast) live in sibling files: `form-demo.tsx`, `overlay-demos.tsx`, `theme-toggle.tsx`.
- `Toaster` is mounted only inside `overlay-demos.tsx` (not globally; T015).
- `pnpm typecheck` needs `.next/types` (`LayoutProps`) from a prior `pnpm build`/`dev` on a clean checkout. Pre-existing.
