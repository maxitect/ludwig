## Deviations and follow-ups

- Added dev dependency `@testing-library/user-event`.
- Added a "Cell grid" section to `/dev/kitchen-sink` (same gating as the existing page) as the test page.
- Backspace: clears the current cell if filled (stays); on an empty cell it steps back and clears the previous one.
- `direction` is controlled (`direction` + `onDirectionChange`). Clicking the active cell toggles it only when the grid already has focus, so the first click on the initial cell does not flip direction.
- `cells` and `highlight` are `ReadonlySet<CellKey>` (`"row,col"` via `cellKey`). `annotation(row, col)` returns `{ content, label }` so the aria label can include it. `accept` receives the uppercased character.
- Keyboard handling lives at the grid root, so it works from both focused cells (Tab in) and the hidden input (tap). Tab leaves the grid at the first/last entry (no keyboard trap).
- No `inputMode` prop yet; digit grids (sudoku) will get a text keyboard until a consumer needs it.
