## Deviations and follow-ups

- **Cell value reaches the hook through the action options, not the answer or saved state.** A cell check is `checkAnswer(puzzleId, null, { mode: "cell", row, col, value })`. Reasons: the generic action cannot extract a cell from an answer whose shape is type-specific, the solver's answer reader returns null while the grid is incomplete, and the saved state is debounced and may lag the keystroke. Cell mode ignores `answer`. `revealCell(puzzleId, row, col)` now returns `{ ok: true, value }`, only that one letter. A type without the hooks gets `invalid` from both. `cellsWrong` was not added.
- `SPEC §4.2` still says the cell options are `{ mode: "cell", row, col }`; it now also takes `value`. I only edited §4.1 (contract and per-cell hooks), §7.4.4 crossword and §7.4.5, as instructed, so §4.2 needs a one-word follow-up.
- **Schema deviation from the ticket text.** `attempts` has no unique `(id, puzzle_id)`, so I followed the gears/rota pattern: `crossword_attempts` carries a trigger-filled `puzzle_id` with FK `(attempt_id, puzzle_id, type_key)` to `attempts`, and `crossword_attempt_cells` FKs `(attempt_id, puzzle_id)` to `crossword_attempts` plus `(puzzle_id, row, col)` to `crossword_cells`. Both fill triggers are in `drizzle/20261003060348_crossword_triggers` and listed in §7.4.5 (the generic crossword example was removed from the first row there).
- **Contract change.** `PuzzleTypeModule` gets optional `checkCell` and `revealCell`; `SolverProps` (in `solver-types.ts`) gets optional `checkCell` and `revealCell` callbacks, which `SolveChrome` supplies (signed-out: sign-in notice). The Check cell and Reveal cell buttons live in the crossword solver, not the chrome. The fixture module implements the hooks so the action tests still cover cell mode.
- **`CellGrid` change (generic):** optional controlled `active` and `onActiveChange`, and a `ref` handle with `focus()`, needed for the active clue and for clicking a clue to focus its first cell. Behaviour is unchanged when they are omitted.
- Letters are stored upper-case (`CHECK ~ '^[A-Z]$'`). `verify` also rejects a clue that contains its own answer as a whole word.
- Content is five original 11x11 quick grids filled by a local script from my own word list (not symmetric, a few crosswordese entries such as SERE and ROTE); clues are original. Titles: Pencil Case, Fresh Ink, Paper Round, Margin Notes, Second Draft. Quality of the fills and clue wording deserves an editorial review.
