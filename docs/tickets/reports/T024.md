## Design notes

- `playwright.config.ts`: `desktop` and `mobile` (390x844, touch) Chromium projects, `trace: "retain-on-failure"`, `baseURL` from `PLAYWRIGHT_BASE_URL`, loads `.env.local` if present.
- Helpers in `e2e/helpers/`: `content.ts` (imports `content/<type>/*.ts` at test time; picks any anagram and any `style: "quick"` crossword), `auth.ts` (unique `e2e-<flow>-...@test.local` emails, sign-up through the UI), `solve.ts`, `db.ts`.
- The DB assertions in the specs run only when `DATABASE_URL` is set and the base URL is localhost, so the same specs run unchanged against a preview (UI assertions only).
- Flow 2 partial resume asserts cell `aria-label` letters after reload, signed out, and again after sign-up and merge (server state).
