## Deviations and follow-ups

- Added `react-chessboard` 5.12.1. Library arrows and arrow drawing are disabled; arrows are our own SVG overlay (`retro-arrow.tsx`).
- Keyboard operation is our own layer (the library's dnd-kit keyboard moves by pixels). The board is one Tab stop (`role="application"`, `aria-activedescendant`); the library's per-piece tab stops are set to `tabindex=-1` in an effect. Cursor starts at e4.
- Pieces are cburnett geometry in our own `pieces.tsx`, filled with `paper` (white) or `ink` (black) and drawn with a stepped hard `shadow` drop-shadow stack (no blur). Black pieces use a paper outline so they read on ink squares.
- Square `Colour`, `PieceKind` and `PieceRow` types derive from `reverse-chess/schema.ts` `Payload`; `Square` is a template literal of the file enum and `number` (rank is a number column).
- `onPieceDrop` returns false: the board is fully controlled, and the parent decides whether the position changes.
- Under emulated reduced motion, the `motion` package (used by the existing SolvedStamp on the kitchen sink) logs a dev-only console warning, as T010 noted. It is not from the board and does not appear otherwise.
- Kitchen-sink section "Chess board" added (`chess-board-demo.tsx`); no temporary routes were created.
- The footer that renders `CHESS_PIECES_ATTRIBUTION` is T015's.
