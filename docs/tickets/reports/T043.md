## Notes

- AC4: the completed attempts were inserted directly into `attempts` (completed_at set) for a freshly signed-up user, not produced by solving in the UI. The hub only reads `attempts.completed_at`, so it exercises the same path as a real solve. Ink screenshots use `localStorage` theme (signed-out).
- Fixtures: AC3 used four generated dailies re-labelled in the ticket DB only (generator_seed NULL, one with max_adjustments=1, daily rows removed). Nothing added to content files.
- Date helper: added `londonDate(at)` to `src/utils/london-time.ts` (same name and signature as T078's). Expect a trivial conflict on rebase onto T078; keep one copy.
- Caching: the catalogue is `use cache` + `cacheTag("puzzles")` + `cacheLife("minutes")`, so it is part of the static shell. Today's card is an async component behind `<Suspense>` that calls `connection()` and reads the London date outside the cache, then calls `getDailyDiagram(date)`, which is cached with the date as part of its key (minutes). The date rolls over exactly at London midnight and a cache entry never serves the wrong day. Publication uses `published_at <= now()`, so the cache lag is at most the `minutes` lifetime.
- Dailies beyond today: the hub only resolves today's row, and the curated queries exclude any puzzle with a `generator_seed`, so future (or past) dailies never appear in the lists regardless of what T078 generates ahead. Tomorrow's slug is still reachable by URL once published, per the play route.
- Extracted `SolvedBadge` and `SolvedIds` into `src/components/puzzle/solved-badge.tsx`; `/reverse-chess` and `/this-week` now use it (third user).
- Added relations `puzzles.gears` and `gearDaily.puzzle` in `src/db/relations.ts` (no migration).
- Decorative gears (`decorative-gears.tsx`, `hub.css`) spin only under `prefers-reduced-motion: no-preference` and without the root `data-reduce-motion` attribute, matching `/reverse-chess`.
- Empty state reuses `Walker` with `aria-label="No diagram yet"`.
- Browser checks ran as isolated headless scripts (`.verification/T043/*.mjs`); the shared Playwright MCP was not used.
