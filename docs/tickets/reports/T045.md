## Deviations and follow-ups

- Enumeration separator (hyphen vs comma) is not in the schema, so every multi-segment answer shows commas, e.g. "(3,4)". A "(5-4)" form needs a SPEC change.
- Clue list is now Across/Down tabs below the grid at every width (scrolls inside 20rem), replacing the two stacked lists. Quick puzzles use it too. `selectDirection` keeps the active cell when it lies in the other direction.
- Type page `/puzzles/[type]` groups puzzles into shelves by style when the type has one (relation `puzzles.crossword`, no migration). Heading text is the lowercase style, shown uppercase by CSS.
- Content: three original cryptics, rotationally symmetric, generated by a local autofill from a hand-written vocabulary (not committed), clues hand-written (def + wordplay). Titles Red Herring, Loose Ends, Fine Print. Not added to This Week. Fills deserve an editorial pass; a few answers (STEIN, PITH, SONAR) are mild.
- `CellGrid` typing wraps to the next playable cell across a block, so after an answer ends at a block the cursor sits on the next run's start.
