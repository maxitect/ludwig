### AC3
Content files carry a formal `rule` per clue (`is`, `isNot`, `either`), used only by `verifyLogicGrid`. Classic: exactly one world, equal to the stored one. Variant: dropping the false clue leaves exactly the stored world; dropping any other clue leaves none or several.
