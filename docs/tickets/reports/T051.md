## Decisions (docs silent, recommended option taken)

- Nothing is **(S)**. The letters and word list are in the payload, so anyone can derive placements; hiding them would be theatre. `loadSolution` derives the placements from the stored grid, and the answer is the two end cells of each selection (either direction). `check` returns only `{ correct }`.
- The solver matches a selection to a word client-side with the pure `derive.ts` (placements are derivable from the payload); the server re-checks on completion.
- The word list is shown to the player, with found words struck through in red and a screen-reader "(found)".
- Content is `{ grid: string[], words: string[] }` (one string per row). rows and cols are derived from it, not stored separately in the file.
- `word_search_attempt_found` has trigger-filled `puzzle_id` and a deferred, non-cascading FK `(puzzle_id, word)`; the seed fails with the standard message if a content edit removes a found word.
- Selection snaps an off-line drag to the nearest of the eight directions. Shared `HighlightPathGrid` (`src/puzzles/_shared/highlight-path/`) is pointer plus keyboard (roving gridcell, Enter/arrows/Enter, Escape cancels).
- The S2E3 quote is an epigraph on the type page (`EPIGRAPHS` in `src/app/(app)/puzzles/[type]/page.tsx`), not added to `lookups.ts` (the row already existed with the name "The Fob-Off").
- Letter tiles (`LetterTiles`, `RungInput`) and `CellGrid` were not reused: selection is by line, not typing.
- Not added to `content/weekly.ts`. Only the migration pair (tables, triggers) was added; the tables migration was hand-edited to make the word FK `DEFERRABLE INITIALLY DEFERRED`, as crossword did.
