## Shared cipher-key API (for T053 and T054)

All in `src/puzzles/_shared/cipher-key/` (no barrel; import files directly).

- `cipher-key.ts` (pure): `ALPHABET`, `Guesses` (`Record<cipherLetter, plainLetter>`, lowercase a-z), `lettersOf(text)`, `cipherLettersIn(ciphertext)`, `decodeLetters(ciphertext, guesses)` (decoded letters in order, `_` for unguessed), `guessesFromLetters(ciphertext, saved)` (inverse, drops anything misaligned), `isComplete`, `duplicatedGuesses`.
- `use-cipher-guesses.ts`: `useCipherGuesses({ ciphertext, savedAnswer, onStateChange, registerCheck })` returns `{ guesses, guess(cipherLetter, plainLetter | null), clear() }`. Guesses are client state. Every change calls `onStateChange({ answer })` with the `decodeLetters` string (null when empty) and the registered check reader returns `{ answer }` only when every distinct cipher letter has a guess.
- `cipher-key-panel.tsx`: `<CipherKeyPanel ciphertext guesses onGuess onClear />`. It renders the ciphertext with guesses under each letter and an A to Z row of input slots (disabled when the letter is absent). Typing fills and advances, Backspace clears, arrows move.

Saved attempt `answer` therefore means "decoded letters so far, `_` for unguessed", and the attempt schema allows `[a-z_]`. A type whose ciphertext is not letters-only (book refs, glyphs) can reuse `Guesses` and the panel by supplying its own symbol-to-letter list; the panel itself currently assumes a Latin-letter ciphertext.
