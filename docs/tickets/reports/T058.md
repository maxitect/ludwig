## Deviations and follow-ups

- Corner-touch rule chosen: a ray through an exact grid corner is blocked only when both flanking cells are obstacles; end cells never block.
- `visibleCells` returns `Cell[]` (not a Set) of non-obstacle cells, including the observer's own cell. `range_cells` is Euclidean, inclusive; `null`/undefined means unlimited.
- Grid is structural (`{rows, cols, isBlocked(row, col)}`); facing keys come from a local const map. T059/T060 should re-derive observer types from their table schemas once they exist (`compass8` enum not yet in code).
