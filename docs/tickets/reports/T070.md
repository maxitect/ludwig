### AC11

Not run. Two things blocked it, in this order:

1. Running `npx @guidepup/setup setup` was refused by the session's permission classifier (external code that changes system settings), so the agent could not start it.
2. It would have stopped anyway. Read from the package source (`@guidepup/setup` 0.29.3, `lib/commands/setup/macOS/setup.js`): with SIP enabled and `/private/var/db/Accessibility/.VoiceOverAppleScriptEnabled` absent, setup opens VoiceOver Utility and waits five minutes for a person to tick "Allow VoiceOver to be controlled with AppleScript" (General tab), which asks for the account password. An agent can't accept that, and the ticket rules out changing SIP.

```
$ sw_vers; csrutil status; defaults read com.apple.VoiceOver4/default SCREnableAppleScript; ls /private/var/db/Accessibility/.VoiceOverAppleScriptEnabled

Error: Domain 'com.apple.VoiceOver4/default' not found.
```

macOS 27 itself is supported (the package's README lists "Golden Gate", and `checkVersion` only needs 11 or later). `@guidepup/playwright` and `@guidepup/guidepup` were installed, then removed again when no spec could use them.

To finish it by hand: run `npx @guidepup/setup setup`, tick the box in VoiceOver Utility, and grant the terminal Accessibility and Automation access when asked.

## Deviations and follow-ups

- **SPEC edits.** §4.5 (On-screen keyboard): `CellGrid`'s entry announcement. §4.5 (Crossword in solve mode): the clue line is `aria-atomic`. PLAN §3 M5 and the E10 row now say "production verification on `ludwigpuzzles.com`". Neither SPEC nor PLAN called production a `*.vercel.app` URL any more, so nothing else changed.
- **AC8 wording.** The AC says the footer shows the cburnett attribution. T144 moved the credits to `/about` and left the disclaimer and an "About and credits" link in the footer (T144 AC3). Verified as built.
- **AC11.** Not attempted beyond reading the setup source; see AC11.
- **The bypass secret reached `example.com`.** To prove `pnpm smoke` targets the origin it is given, it was run once against `https://example.com`. `playwright.config.ts` adds `x-vercel-protection-bypass` to every request whatever the base URL, so two requests to `example.com` (IANA's reserved domain) carried the secret. Rotating `VERCEL_AUTOMATION_BYPASS_SECRET` is the safe response and needs the user (a Vercel setting). A follow-up could make the config send the header only to Vercel-hosted origins.
- **The live clue line and typing.** Not changed: typing a letter does not re-announce the clue.
- **Follow-up tickets suggested** (larger than a label or role fix): (1) name the entry in every crossword cell's label ("1 Across, letter 2"); (2) announce a completed chess move ("pawn a6 to a5") in the board's live line; (3) a real VoiceOver run once AppleScript control is enabled by hand.
- **Unrelated, seen while working:** a `next dev` from 2026-11-10 is still listening on port 3000 in the main checkout and answers 500 (`Can't resolve '@vercel/turbopack-next/internal/font/google/font'`). Left alone; it isn't this ticket's server.
- `brand.mts` was run twice against production by mistake (three extra page loads).
