## Design

- Migration `20261006212517_crossword_segment_separator_required`: backfills non-last NULL separators to 'word', then replaces the T074 trigger function. Same deferred constraint trigger, now per affected clue (OLD and NEW): every segment but the last must have a separator, the last must not. The snapshot is unchanged from the previous migration's (custom SQL only).
- The column stays nullable (the last segment is NULL by design).
- `deriveEnumeration` throws on a non-last NULL instead of reading it as a word break. `load.ts` needed no change (it passes the column through).

## Backward compatibility (PLAN §5.1)

The previous deploy (`main`) writes `separators?.[position] ?? "word"` on every non-last segment and NULL on the last in `src/puzzles/crossword/module.ts` `upsertContent`, so it satisfies the new trigger. A Vercel rollback reuses an existing build and doesn't re-run the seed.
