## Design

- Migration `20261006212517_crossword_segment_separator_required`: backfills non-last NULL separators to 'word', then replaces the T074 trigger function. Same deferred constraint trigger, now per affected clue (OLD and NEW): every segment but the last must have a separator, the last must not.
- The backfill runs before the function swap in the same migration. The column stays nullable (the last segment is NULL by design).
- `deriveEnumeration` no longer reads NULL as a word break; it throws on a non-last NULL. `load.ts` needed no change (it passes the column through).
- SPEC §7.4.4 crossword row updated. §7.4.1 has no separator text, so it needed no change.

## Backward compatibility (PLAN §5.1)

The previous deploy is T074 or later. Its `upsertContent` writes 'word' (or 'hyphen') on every non-last segment and NULL on the last, so it satisfies the new rule. A Vercel rollback reuses an existing build and doesn't re-run the seed. Confirmed from `src/puzzles/crossword/module.ts` on main.
