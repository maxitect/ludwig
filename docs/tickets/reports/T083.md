## Decisions and notes

- Content: first-link (1), big-wheel (2), side-step (2), cross-wires (3), the-station (4), last-departure (5). Built by planting a chain, then adding bolts and pruning until `solve` gave one placement. The spec gives no detail of the detectives' board, so "The Station" is a new layout (mixed 8/16/24 cogs including a 3-4-5 diagonal mesh). `publishedAt` is 2026-10-07 (the sandbox clock).
- Cog drawing: `cogPath`, `polar`, `round` extracted from the gears board to `src/puzzles/_shared/cog-path.ts` (gears board now imports them).
- Engine: only `reachableFrom` exported. Jam cogs, unneeded cogs, refusal text and status line are pure helpers in `gear-train/play.ts` with unit tests.
- Spin is a CSS animation per cog (period 3 s x teeth / 8), not `motion`; reduced motion (OS or account) draws arrows instead.
- Tray: tap or Enter selects a size; drag from the tray places on the peg under the pointer; tapping a placed cog or Delete removes it.
- Check feedback is the chrome's generic one; the status line carries the detail.
- New e2e: `e2e/gear-train.spec.ts` (7 tests x 2 projects pass), helper `gearTrainAttemptFor`.
