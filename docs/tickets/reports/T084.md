## Notes

- Migrations `sudoku_region_tables` (additive) and `sudoku_region_triggers` (deferred constraint triggers on set insert and cell update/delete); backward compatible.
- Engine takes `Units`; `unitsFor(regions)` gives classic, jigsaw (rows, columns, regions) or rainbow (classic plus groups). Existing signatures keep a classic default. `generate.ts`/`grade.ts` stay classic only.
- `check` returns only `correct` and `wrongParts` (rule breaks); `loadSolution` solves with the puzzle's units.
- `upsertContent` upserts the region set and cells in place, and deletes the set when content has none.
- Region overlay: `_shared/region-borders.ts` (cell classes and SVG segments) and `_shared/preview/region-borders.tsx`, reusable by star battle. `MiniGrid` gained a `tints` slot; `DigitGrid` forwards `annotation` (group letters).
- Design tokens `--rainbow-1..9` added to `globals.css` and SPEC §6.2 (same in both themes since grids stay paper).
- `raw-tokens.test.ts` allowlist moved `border-ink` from the sudoku solver to `region-borders.ts`.
- Content: jigsaw `torn-edges`, `loose-pieces`, `broken-frame`; rainbow `test-card`, `colour-bars`, generated from solutions backwards by a throwaway script (not committed). Rainbow groups are the same-position-in-box layout (`test-card`) and a Latin shift (`colour-bars`).
- e2e `sudokuPuzzle()` now picks a classic puzzle; the axe spec covers the two variant pages.
