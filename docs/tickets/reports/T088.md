## Deviations and follow-ups

- Migration `troix_tables` is additive (enum, four tables, FKs). No triggers: the generic subtype-row trigger already covers the new `puzzle_types` row.
- `CellGrid` gained an optional `onCycle` prop (and `inputMode: "none"`): a tap, Enter or Space calls it instead of toggling the typing direction. It is the one change to a shared file; other grids are unaffected. `region-mark-grid.tsx` was not reused: Troix has no regions and needs read-only givens and typed keys, which `CellGrid` already provides.
- No on-screen `PuzzleKeyboard`: a tap cycles X, O, I and empty, so the system keyboard is suppressed with `inputMode="none"` on touch.
- Like futoshiki, `check` ignores the stored solution (none exists): any complete grid that obeys the rules and the givens is correct, since uniqueness is proven by `puzzles:verify`. Over-quota lines name the cells holding the over-quota symbol.
- Symbols are drawn in the hand font via `CellGrid`; givens use the display font like other grids.
- Content (3 files at 9x9, 2 at 6x6) was authored by a throwaway generator (random valid grid, greedy removal of givens while `countSolutions` stays 1); it is not committed. Each 9x9 solves in under 25 ms.
- Added `e2e/troix.spec.ts`, `troixCells` in `e2e/helpers/db.ts` and `troix` in the axe type list.
- SPEC §6 (solve mode, on-screen keyboard bullet) now records that Troix needs no pad: a tap cycles the cell and its hidden input always has `inputmode="none"`.
