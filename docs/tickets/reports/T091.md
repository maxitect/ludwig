## Design notes and deviations

- **Tables** as SPEC 7.4.4 with the item region columns named `x, y, width, height` (SPEC said `w, h`; SPEC updated). `attempt_found (puzzle_id, position)` FK to the items is `DEFERRABLE INITIALLY DEFERRED` with no cascade, edited into the generated migration like word-search. Triggers are in `detective_scene_triggers`, as for spot-difference.
- **Payload** carries `puzzleId, sceneKey, width, height, itemCount`. Nothing else.
- **Answer** is each find as `{x, y, title}` (the region centre and the canonical title), and `check` re-runs `matchFind` for every item, so a client cannot claim a find the server would not accept.
- **Actions** `tryFind` (match on the server, return only that item), `loadFoundItems` (ring and list saved finds after a reload) and `revealScene` (all titles and regions, a `reveal_all` hint for a signed-in player). As in spot-difference, `loadFoundItems` takes client-supplied positions, so it can be asked for any item. It exposes nothing `revealScene` doesn't, which is open to everyone by design.
- **Shared code:** the region helpers moved to `src/puzzles/_shared/regions.ts` and `spot-difference/regions.ts` re-exports them (both types call them). The sector overlay stays per type: spot-difference draws it over two scenes, here it sits in the transformed layer.
- **Solver:** pan and zoom through pointer events (`view.ts`, tested): drag to pan, pinch, ctrl-wheel, zoom buttons, `+`, `-`, `0`. Rings use non-scaling strokes and markers keep a constant pixel size at any zoom. The keyboard cursor pans itself into view when zoomed.
- **Scene** `fixture-street` is a 1200 by 800 SVG component in the current text colour (so it takes the ink of the panel in both themes) with three signs. `verify` does not require 10 titles (the fixture has 3); T092 can add a minimum with the real scene.
- **Preview:** generic street frame with one red ring per title (up to five), so a large real scene never breaks the node budget.
- **No `bg-paper` or other raw token** was added, so no `raw-tokens.test.ts` entry.
- **Not done (out of scope):** the real artwork and launch content (T092).
