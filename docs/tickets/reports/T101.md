## Design

- `troix/generate.ts`: generator `troix`, version 1, registered in `src/puzzles/generators.ts` (generator and grader). Per candidate: a size (d1 6x6, d2 6x6 or 9x9, d3 to d5 9x9), a random filled grid by seeded backtracking, then givens removed in shuffled order while the grader, held to the target level, still solves it. Kept when the grade equals the target and `countSolutions === 1`.
- `troix/grade.ts` (`solveTroix`, `gradeTroix`): per-cell symbol domains. Ladder: line at quota and pair ends (1), gap rule (2), only places: a symbol a line needs with exactly that many cells able to hold it (3), line arrangements: enumerate every valid arrangement of one line and drop symbols none uses (4), contradiction (5).
- Level 5 is a one-step what-if: assume a symbol in a cell, run levels 1 to 4 to a fixpoint, and rule the symbol out if that reaches a contradiction. It is no nested guessing, but it is the one technique that resembles trial and error; without it every puzzle minimal under levels 1 to 4 grades 4 or less and the given count barely changes (29 to 35 givens at 9x9 for levels 2 to 4), so the given count could not separate difficulties 4 and 5.
- SPEC "Generated content" lists troix.
