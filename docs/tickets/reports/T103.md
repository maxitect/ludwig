## Design

- `kakuro/grade.ts` (`solveKakuro`, `gradeKakuro`): reads only the white cells and derived clues, never the digits, on the shared `candidates.ts` state (units are the runs). Ladder: **1** naked single, combination table (each open cell of a run is limited to the digits of the combinations for its sum that hold the digits already placed; two runs' limits intersect in the shared cell); **2** run intersection (a combination is also dropped when its digits cannot be reached by the cells' pencil marks); **3** hidden single (a digit every open combination of the run holds, which only one open cell can take); **4** implicit pair (shared naked pair) and hidden pair (two required digits fitting the same two cells); **5** run consistency (a digit stays in a cell only if some combination of the run places it there with every other digit placed in the run's other cells). All are direct deductions within one run; nothing assumes a value and propagates it. The shared `hiddenSingle`/`hiddenSubset` are not used: they assume every digit appears in the unit, which is false for a kakuro run.
- `kakuro/generate.ts`: generator `kakuro`, version 1, registered with its grader in `src/puzzles/generators.ts`. Per candidate: a size from the difficulty (6 to 7 at d1 up to 10 to 11 at d5); a layout of first row and column black, long runs split, then random black cells accepted only if no run becomes a single cell and the white cells stay in one piece; a weighted fill (extreme digits favoured at low difficulty) with no repeat in a run; then **repair**: single-digit changes (biased 70% to cells the grader could not place) kept unless they move away from "solved by the techniques up to the target with the target as hardest needed". The exact `countSolutions` runs only once, on the kept puzzle, since a technique solve proves uniqueness.
- **Ticket conflicts, research wins.** The ticket says repair until `countSolutions === 1`; the one-off script's hill-climb on the exact solver did not finish at 10x10. Repair is gated on the technique grader instead (research §5.2). The ticket's "combination-table singles, run intersections, implicit pairs" ladder is extended with hidden single/pair and run consistency to reach five levels.
- 180 degree symmetry is not implemented (optional in the ticket).
- SPEC §4.6 "Generated content" lists kakuro.
