## Notes

- Icons: the red L from `src/app/icon.svg` on paper (`#E9E4DE`), no baked corners. Made by `scripts/dev/make-icons.ts` (headless Chromium via `@playwright/test`, no new dependency). The maskable icon uses the L at 1x (inside the safe zone); the others at 1.3x.
- Theme colour values live in `src/config/theme-colors.ts`, with a test that they match `--color-paper` and `--color-ink` in `globals.css`.
- A hand-chosen theme gets its own `theme-color` meta (`#theme-color-override`), prepended to `<head>` by `themeInitScript` and kept in step by `applyTheme`; "system" removes it. The media-query metas React renders are never edited. Its hex is lowercase so React, which matches hoisted metas by name and content, never claims it (see Review).
- `layout.tsx` diff: imports plus the `viewport` export; the head scripts render through T126's `InitScript` (rebased onto it).
- Manifest `theme_color` is Paper (a manifest cannot vary by scheme).
- Install hint: `src/components/shell/install-hint.tsx`, rendered in the mobile nav sheet. iPadOS desktop-class UA (Macintosh with touch) counts as iOS; Chrome/Firefox/Edge/Opera on iOS are excluded.
