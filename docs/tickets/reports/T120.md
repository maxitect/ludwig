## Decisions

- Guard is a Vitest test (`src/config/raw-tokens.test.ts`) with a per-file allowlist; a second test fails if an allowlisted file stops using its token.
- New `--hand` token (crayon in Paper, paper in Ink): crayon on an ink card is under 2:1. `text-crayon` on panels became `text-hand`; grid cells keep `text-crayon` on paper.
- Ink `--destructive` is `ludwig-red` (3.2:1 on ink, fine for the underline and fills); blood is not legible there. Ludwig-red text on ink (form messages) is left to T124.
- Ink `--cast` is paper at 45% (3.8:1). Arbitrary shadows use `var(--cast)`, since `@theme inline` does not emit `--color-cast`.
- Grids stay paper with a light frame and cast: `CellGrid`, `HighlightPathGrid`, logic grid `MarkGrid`, chess board, rota squares. Spot the difference frame stays paper too.
- Chess piece drop shadow (`pieces.tsx`) is allowlisted for T121.
- Selected toggles use `bg-muted text-foreground` instead of `paper-deep`.
