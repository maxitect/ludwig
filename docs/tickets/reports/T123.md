## Notes and decisions

- Design kept option B. Old root snapshot on top with a 36-point torn polygon (evenodd) around `--vt-x/--vt-y`, 400ms ease-out; new root underneath fades 300ms after 200ms. `BulletHoleTransition` records the click point (keyboard activation uses the element centre) and `--vt-r`, the radius that clears the farthest corner, in a document click listener. Lengths are `calc()` px, so the hole is circular at any aspect ratio.
- The React root-snapshot workaround (cancelling React's hiding animations and `view-transition-name: root !important`) is still required: removing the `!important` rule made the tear disappear entirely. Fallback option C was therefore not needed, and SPEC §6.3 only has its description line updated.
- Grid now uses `grid-blue` at a 24px pitch (was `--ring`).
- `scrollbar-gutter: stable` on `html` removes the scrollbar jump.
- The spec's "No fades" rule is bent for the new-page fade, as the ticket requires.
