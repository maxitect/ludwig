## Notes

- Font size is `max(14px, min(1.125rem, (100cqi - 36px) / (LINE_WIDTH * 0.52)))` on the book `ol` inside an `@container/book-page`. The nowrap switch is a generated `@container` rule whose threshold derives from `LINE_WIDTH`, `JOST_EM_PER_CHAR` and the 14px floor (all in `solver.tsx`); below it lines wrap with a hanging indent, `↪` markers (measured with a layout effect plus ResizeObserver, `aria-hidden`) and alternate bands.
- At `lg` the solver breaks out of the solve page's `max-w-3xl` by `-mx-24`, with a `14rem` references column, so the book panel gets about 576px of text.
- Phones: References panel is ordered above the book (two columns at 30rem and up); Previous/Next stay on one row with short visible labels and `aria-label`s.
- A worst case of 56 all-`m` characters cannot fit any readable size; the width check uses wide-letter English-like text and the seeded books.
- `solver.test.tsx` stubs `ResizeObserver` for jsdom.
