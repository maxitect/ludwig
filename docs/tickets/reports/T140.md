## Deviations and notes

- **No `[data-seq-scroll]` block existed.** The fallback is the base (paused, negative-delay) rule set and the native timeline is the `@supports` override, so each new element is added to both lists, not to a third block. `ScrollFallback` now sets `data-seq-scroll` on `.title-sequence` while it is active, so AC7's attribute check works.
- **Wide-screen peak.** At 22deg the side wall covers only 4% of a 1280px viewport at the crossing, so the peak is `--seq-peak`: 22deg below 64rem, 44deg from 64rem, 62deg from 110rem (the last tier measured at 1920 only). Calm angles are `--seq-calm` as in the ticket.
- **Timings retimed.** Wall swaps are 30-36% (Grid to Board) and 62-68% (Board to Mirror). The Mirror wall stays opaque after 88% so the digits are visible at 0.92. Captions were retimed to match.
- **Computed `translate`.** Browsers serialise `translate: 0 0` as `0px`, so the spec reads the two components as numbers (missing y is 0) instead of comparing `"0px 0px"`.
- **Seek rounding.** The spec rounds the scroll offset up so progress never lands a pixel short of a keyframe boundary; opacity changes under 0.02 are treated as pixel rounding.
- AC7's pawn check compares against the translate expected from the element's own `--seq-progress`, since the pawn is mid-move at 0.50 (its move runs 47-51%).
- `INK` renders its shared I invisibly, so the I is not drawn twice.
