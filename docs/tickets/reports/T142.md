## Changes

- `SolveSlot` takes a `fallback` that renders in place on the server and during hydration (`useSyncExternalStore` with a false server snapshot, so the hydration pass matches the HTML), then the portal takes over. The crossword passes its clue bar as the fallback, so the largest text (the LCP element) is in the first HTML. Hidden above the `touch` breakpoint.
- Radix Tabs moved to `src/puzzles/crossword/clue-tabs.tsx`, loaded with `lazy` and `Suspense` (server-rendered, hydrated when the chunk arrives), so the clue bar needs no Tabs code.
- Reverse chess: `DeferredChessBoard` loads `react-chessboard` through `Deferred` after hydration. The LCP element there is the "What was the last move?" heading, so the board code left the critical path. A square of the board's size (border and shadow included) holds its place: CLS stays 0.
- Caveat Brush and JetBrains Mono: the Google Latin files subset to U+0020-007E with fonttools (`pyftsubset`, scratchpad venv) and committed in `src/app/fonts/`, loaded through `next/font/local` (52 to 43 KB and 40 to 31 KB). Same `preload: false` and `display` as before.
- `scripts/dev/lighthouse.ts` writes to `.verification/$TICKET/` (default `T069`).
- `solver.test.tsx` awaits the lazy tabs (`findBy`), no assertion changed.
