## Art notes

Source scans (all from Wikimedia Commons, licence taken from each file page): Le Keux plates and Doré, "Public domain"; Neale, "No restrictions"; Hogarth (Met), CC0. No attribution-required flag on any file. Each was cropped to the plate, converted to grey with per-plate levels, scaled to 1600 px (no upscaling), then edited and passed through `prepare-scene.ts`. Every edit was done in matching hatching by cloning the plate's own hatching and bricks (feathered), and tiling for window blanks, then compared side by side against the original at 2x to 4x; edits that read as smudges (a dormer, a window, a barrel and a chimney, the Hogarth shield) were redone. Edit types: removed or added windows, chimneys, a cross, figures, a dog, sheep, a barrel, a lantern; added birds. All are structural, none tone-only. Editing scripts sit in `.verification/T146/work/` (git-ignored).
