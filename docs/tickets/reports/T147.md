## Deviations and follow-ups

- Decision taken without the user (recommended option each time): the ciphertext and axe regressions were fixed in the product by tightening the touch Check row spacing, not by weakening or skipping the specs. One side effect: on touch phones the status line now takes space only when a notice appears, so a notice shifts the solver by about 28px on touch layouts.
- flow-1 (mobile) failed only through `clickCheck`, not through sign-up. It passes locally. PR #96 (the `@e2e.test` sign-up helper) is not in this branch, so a rebase may be needed after it merges.
- AC10 follow-up: if it still fails on the preview, the likely fix is `display: "optional"` on the display font, or `size-adjust` fallback tuning; that is a visual decision beyond this ticket.
- The local Firefox build crashes at launch ("Could not find profile folder"), so landing-fallback was only verified by the CI run on this PR.
