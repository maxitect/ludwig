## Deviations and follow-ups

- Decision taken without the user (recommended option each time): the ciphertext and axe regressions were fixed in the product by tightening the touch Check row spacing, not by weakening or skipping the specs. When a notice appears on a touch phone, the status line (32px) takes its space from the solver scroller. Check, Reset and the on-screen keyboard do not move (measured on iPhone 15 and 390x844).
- Visual effect of the font changes: with `optional`, a first visit on a slow connection keeps the metric-matched fallback for display text for that page view (Josefin is preloaded, so this is rare). With `block`, hand-font text stays invisible for up to 3s until Caveat Brush loads, instead of flashing a fallback.
- Follow-up: on Linux and Android, Jost (body, `swap`) also lacks its Arial-based fallback metrics, so a slow Jost load shifts body text by about 3px (reproduced with fonts delayed 300ms in the Linux image). CI does not hit it because Jost is preloaded.
- Follow-up (decision): AC9's 4x throttle budget from T140 was calibrated on a fast machine and fails on some GitHub runners. Options: calibrate the throttle rate to a CPU benchmark, or run AC9 outside the preview suite.
- flow-1 (mobile) failed only through `clickCheck`, not through sign-up. It passes locally. PR #96 (the `@e2e.test` sign-up helper) is not in this branch, so a rebase may be needed after it merges.
- The local Firefox build crashes at launch ("Could not find profile folder"), so landing-fallback was only verified by the CI run on this PR.
