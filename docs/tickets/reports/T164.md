## Deviations and follow-ups

- **Migration shape.** `ALTER TYPE ... ADD VALUE` cannot be used by a generated column in the same transaction, and `drizzle-kit migrate` runs all pending migrations in one. `20261107165832_rota_the_case` therefore rebuilds `rota_clue_kind` (drop the three subtype `kind` columns and their FKs, retype `rota_clues.kind`, re-add) and `..._triggers` recreates `trg_rota_clues_require_subtype` and adds `rota_clue_not_instigator_fill_puzzle_id`. New NOT NULL columns are backfilled in the migration (`brief` placeholder, victim = alphabetically first worker, empty `excuse`) and corrected by the next seed. The victim, speaker and attempt-instigator FKs are hand-edited to `DEFERRABLE INITIALLY DEFERRED` (drizzle cannot declare it), no cascade.
- `rotaPuzzles`' extra-config callback has an explicit return type to break a TypeScript cycle with `rotaWorkers`.
- Seed inserts a new puzzle row with a placeholder `victim_worker_id` (random uuid, deferred FK) then updates it once workers exist.
- Epilogue array renders as a `list-none` `<ol>` (steps are self-labelled "Step n:"), the confession line is the last item.
- Source labels for unspoken clues are derived from kind (`adjacent_only` Site rule, `unpowered_square` Site log, `max_swaps` Supervisor), not stored.
- Brief bold markup is `**zone**` in the stored text; `verify` requires both zones named and bold.
- SPEC edits: §5.1 Mode D (payload, clue kinds, answer, summing-up, case sheets), §7.4.4 rota row; research note §7 status.
- AC8 (preview `run_sql` and `vercel curl`) is verified after the single push.
