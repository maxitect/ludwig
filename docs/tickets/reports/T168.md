# T168 report: Solve mode on tablets (iPad)

Status: DONE
Branch: ticket/T168-solve-mode-on-tablets
Verify cycles: 2

## Decision

Widened the existing `touch` variant instead of adding a tablet variant:
`(pointer: coarse) and ((max-width: 47.999rem) or ((min-width: 48rem) and (min-height: 37.5rem)))`.
Portrait phones are unchanged. Touch tablets (768px or wider, 600px or taller) get solve mode in both orientations, so every solver, the page shell, header/footer hiding, the pad and `--solver-height` apply with no second set of classes. **Landscape phones** (under 600px tall) are excluded by the height floor and keep the desktop layout. `touch-short` is now built on the same query (a landscape iPad mini, about 700px visible, gets the tighter cipher spacing). `TOUCH_QUERY` is exported from `keyboard-store.ts`; `touch-query.test.ts` fails if `globals.css` differs. The bottom slot (pad, clue bar, cipher key) is `max-w-xl` and centred; the crossword grid is centred (`touch:items-center`).
